# Career-Code Job Portal Client — Slide Deck (Text Version)

## Slide 1: Project Title
- Career-Code Job Portal Client
- Role-based modern job portal frontend
- Built with React + TypeScript + Vite

## Slide 2: Problem We Solve
- Job seekers need a simple application experience
- Recruiters need structured hiring workflow
- Admin needs platform-wide oversight

## Slide 3: User Roles
- Candidate
- Recruiter
- Admin

## Slide 4: Candidate Features
- Job browsing and filtering
- Job details view
- Apply with resume and cover letter
- Track application status

## Slide 5: Recruiter Features
- Create and manage job posts
- Review applicants
- Update hiring pipeline statuses
- Role-specific dashboard insights

## Slide 6: Admin Features
- User and activity monitoring
- Platform moderation tools
- High-level metrics and analytics

## Slide 7: Tech Stack
- React 18 + TypeScript
- Vite
- React Router
- TanStack Query
- Tailwind CSS
- Axios + Zod + React Hook Form

## Slide 8: Architecture Overview
- Component-based UI layer
- Context and hooks for shared state
- Service layer for API integration
- Feature-based route/page organization

## Slide 9: Development Workflow
- `npm install`
- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run build`

## Slide 10: Deployment
- Production build through Vite
- Vercel-ready configuration included
- Runtime API URL via environment variables

## Slide 11: Quality Focus
- Type safety across app layers
- Query cache and invalidation patterns
- Reusable UI primitives
- Structured folder organization

## Slide 12: Next Steps
- Continuous feature improvements
- UX refinements for all roles
- Better analytics and reporting depth
